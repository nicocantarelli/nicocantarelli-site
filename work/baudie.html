The constraint

Almost everything in a Shopify store is yours to shape. You can rebuild the product page, restructure the cart, replace the theme entirely. Checkout is the exception. Theme code does not run there, so the one moment when a customer has already decided to buy is the one moment you cannot reach with the tools you use everywhere else.

Baudie wanted to offer a relevant add-on at exactly that moment, and wanted the founder to be able to change what was offered without waiting on a developer.

The decision

The straightforward version is to build the whole thing in the extension: read the cart, decide what to offer, and apply the discounted price from the client. It is less code and it works in a demo.

It is also wrong. Anything running in the browser can be changed by the person running the browser, and a discount decided there is a discount a customer can rewrite. Pricing is not a presentation concern.

So the work is split in two. A Checkout UI Extension, written in Preact, queries the Storefront GraphQL API for product and variant data and decides what to show, if anything. A Shopify Discount Function, running on Shopify's servers, holds the pricing rules and applies them. The extension can suggest. It can never decide what a customer pays.

The rules themselves live in metafields rather than in the function's code, so changing an offer is an edit in the Shopify admin rather than a deploy.

Testing

Discount logic is the kind of code that fails quietly. Nothing errors, nothing appears in a log, and the store simply sells at the wrong price until somebody notices in the numbers weeks later.

Pricing and eligibility rules are covered by an automated suite that runs before anything ships. It is the least visible part of the build and the part that lets the founder change offers without asking whether it is safe to.

The rest of the build

  • Custom Online Store 2.0 theme: 44 modular Liquid sections, 24 JSON templates
  • Metafield-driven product pages, bundles and landing pages
  • Custom AJAX cart drawer with cart-level upsells
  • Klaviyo, Gorgias and Videowise integrations
  • Transactional notification templates in Liquid
  • Releases through Shopify CLI, Git and GitHub
